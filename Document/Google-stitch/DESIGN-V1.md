# Design System: FlowAccount Receipt Sync

## Visual Identity & Vibe
- **Style:** Professional B2B SaaS, FinTech Clean, High Trust, and Efficiency.
- **Layout:** High-density data layouts with scannable sections, utilizing cards and split-panes for validation tasks.

## Exact Color Palette
- **Primary (Brand):** `#066DF5` (Flow Blue)
- **Secondary/Accent:** `#0F172A` (Slate Navy)
- **Success:** `#10B981` (Emerald Green)
- **Warning/Alert:** `#F59E0B` (Amber Yellow)
- **Danger/Error:** `#EF4444` (Rose Red)
- **Background (App):** `#F8FAFC` (Light Slate)
- **Background (Surface/Card):** `#FFFFFF` (White)
- **Border/Divider:** `#E2E8F0` (Slate Gray)

## Typography
- **Font Family:** `Inter`, sans-serif (Fallback: system-ui)
- **Headings:** Bold, Navy (`#0F172A`)
  - H1 (Page Title): `24px` / Line Height: `32px`
  - H2 (Section Title): `18px` / Line Height: `24px`
  - H3 (Card Subsection): `14px` / Line Height: `20px`
- **Body Text:** Regular, Slate (`#334155`), `14px` / Line Height: `20px`
- **Captions/Labels:** Medium, Slate (`#64748B`), `12px`

## Component Specifications
- **Buttons:**
  - *Primary Button:* `#066DF5` background, white text, `8px` border-radius. Active/Hover states included.
  - *Secondary Button:* White background, `#334155` border and text.
- **Form Inputs:**
  - Standard height: `40px`, border `1px` solid `#E2E8F0`, radius `6px`.
  - *Focus State:* Border `#066DF5` with a subtle outer glow.
  - *Error State:* Border `#EF4444` accompanied by a small red error message below the input field.
- **Status Badges:**
  - Small pills with light background tint and dark text (e.g., Success: Light green bg with dark green text).
- **Shadows:** - Subtle cards shadow: `0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1)`
